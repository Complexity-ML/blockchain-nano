# InventoryBridge V2 — exécution native et divergence différentielle

Le 25 octobre 2026, le lot fermé InventoryBridge V2 a exécuté **24 cas Solidity, 65 transactions et 22 comparaisons avec l’oracle comptable** dans le moteur C++ Nano, en processus sur AMD64 avec le profil Shanghai explicite. Les 65 débits de gas et crédits au bénéficiaire ont été vérifiés. Il s’agit d’une qualification d’exécution locale, sans bloc miné ni consensus réseau : [adoption indépendante](native-adoption.json), [contrôleur natif](native-controller.json).

Le [build du programme de test](build-result.json) a réutilisé le cœur existant `a1475733637348e9a22e72d6f8be3d61ebeafb39443cb168110ca353781ae2e6` sans le recompiler ni construire une image. La source native était `a67130f81a770dcefdf79bb01353397a9abcea5c`. L’exécution Docker et le processus C++ sont sortis à zéro. Le premier post-vérificateur a ensuite échoué en cherchant un nom de fichier incorrect ; son [échec original](native-post-validator-result.json) reste conservé. L’adoption indépendante a seulement relu les résultats existants et observé la clôture, sans rejouer de transaction. Les JSON provisoires `passed:false` ne sont pas transformés en verdict autonome.

Le [rejeu différentiel des mêmes transactions signées](rawdiff-controller.json), piloté à la source `4c6529cbdff320ec8db9060bc6cb899fee4b1e2a`, a **échoué à la transaction 3**. Les deux premières racines étaient identiques. À la troisième, le statut, le gas (`9 372 460`), le hash, le nonce, les champs signés, le contexte de bloc et les soldes contrôlés correspondent ; seule la racine d’état diffère. La [trace](rawdiff-trace.json) conserve les racines Nano `0x31b8ce7f3b16c67e7e7ef1faf86b5360b25aba1532b2747ed70381bc3261f4c5` et Anvil `0x6f1e5613847ffe207fe03c2e6f2ada0f8c591296b0a2020d757c1547ce9675bc`. La cause n’est pas établie ; le [résultat externe](rawdiff-root-result.json) reste en échec. Les 62 transactions restantes ne sont pas qualifiées par ce rejeu arrêté.

Ces résultats ne qualifient ni la conformité générale EVM/RPC, ni un fork activé sur le réseau, ni le bridge authentifié ou sa finalité source. Aucun statut EIP n’est promu. L’écart de gas de 324 avec le précédent scénario à adresses/calldata différents reste historiquement inexpliqué ; il n’est pas effacé par l’égalité du gas sur ce préfixe exact. Les échecs antérieurs, dont la campagne 04, restent ouverts dans leur périmètre. Les allocations, le ratio de conversion — notamment aucune adoption implicite de 1:1 —, la réserve, le lancement Doppler et l’économie réelle restent à définir et à qualifier. Aucun actif réel, vente ou déploiement public n’a été autorisé par ce lot ; la production demeure non qualifiée.
