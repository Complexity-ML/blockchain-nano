Les quatre sources OPS sont épinglées au lot `98205612…` revu indépendamment. Les reçus ROOT attestent la configuration, le SDK/P2P, l’admission du cache, le build canonique et le nouveau test d’installation sur Linux ARM64 et AMD64 dans les environnements Docker de dépendances existants. Ce rapport qualifie ces sources épinglées ; la livraison Git est vérifiée séparément.

Le correctif rétablit la correspondance entre le contexte Docker, les cibles installées et leurs contrôles : `.dockerignore` admet les deux sous-arbres C++ `tools/storage-maintenance` et `tools/consensus`, ainsi que `notices.sha256` ; le Dockerfile construit les quatre cibles natives que CMake installe, en plus du P2P construit séparément ; la vérification des bibliothèques couvre les cinq exécutables. Les programmes ne reçoivent aucune clé opérationnelle ; le répertoire de travail doit rester vide. Chaque lancement est borné à cinq secondes, l’installation à vingt secondes et CTest à soixante secondes. La branche historique `installed_node` reste distincte et n’est pas sélectionnée par ce nouveau test.
