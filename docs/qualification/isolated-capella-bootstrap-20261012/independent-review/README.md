Le driver réel utilise six hashes littéraux provenant des reçus déjà conservés, sans recalcul des pins à partir des entrées courantes. Il marque les copies, clés chargées, lecture de disques, horloge, finalité commune, runtime, réseau et production comme non exécutés/non qualifiés.
