# Doppler : intégrité des revues et garde du fork privé

Le lot ajoute un lecteur offline des revues unsigned, impose le checkpoint du fork privé avant toute impersonation et compare le minimum encodé au delta de jetons réellement reçu. La configuration approuvée doit être fournie séparément avec son SHA ; changer ensemble un texte de revue et son calldata ne remplace pas cette autorité externe. Le lecteur garde `simulationVerified:false`, `nativeAssetRelationshipVerified:false`, `signed:false`, `broadcast:false` et `productionReady:false`.

Root a qualifié les sources dans un espace isolé, sans modifier les fichiers de la campagne03 : [33 nouveaux cas](targeted.stdout.tap), puis [4 intégrations de la vraie CLI](cli.stdout.tap), tous terminés exit0. Les quatre cas CLI vérifient le résultat positif lié aux deux pins, le refus d’un SHA incorrect sans fichier de sortie, le refus d’un lien symbolique et la conservation d’une sortie déjà présente. Les 33 cas n’ont pas été rejoués pour les quatre suivants. Les rapports [API](result-public.json) et [CLI](cli-result-public.json) conservent leur portée. Le premier journal contient le reporter standard Node, le second le format TAP.

Les tests réutilisent SDK1.0.43, viem2.33.3 et router1.0.15 déjà installés, avec dépendances/lock inchangés et `fetch` interdit par preload. Aucun RPC réel, wallet, Anvil, signature, broadcast, installation ou build d’image n’a été exécuté par ces tests. Les tests Node sont une qualification des outils unsigned, pas une compilation ou qualification du moteur C++ dans Docker.

Le garde de fork vérifie chaîne locale31337, client Anvil et header initial conservé Base52173454 (`0xba5cc2e9e91ce6f64babb91e8bbf5a38d71e9f2fd01bc17473519a5c3dc6be5d`). C’est une comparaison RPC à une fixture publique historique, pas une preuve de finalité Base. Le cas devis100/minimum99/sortie1 est refusé même avec un ancien solde positif. Le nouveau driver complet Anvil n’a pas encore été rejoué ; les anciennes migrations/LP et simulations, dont le rejet Base, restent historiques et ne sont pas requalifiées par ce lot.

Le jeton standard Doppler est préémis ; le gateway de représentation actuel démarre avec une offre nulle. Leur invariant d’offre n’est pas contourné. Une description de relation native, même byte-identique, ne qualifie ni réserve canonique, conversion, remboursement, ratio, couverture ou confiance du bridge. Les spécifications économiques et la revue indépendante restent ouvertes.

Ce changement JavaScript/documentaire ne modifie aucun fichier C++, de harnais multihost, de profil, de clé, journal ou témoin de la tentative03 active. La candidate binaire reste issue de1925 ; cette campagne garde son sourceBase85f et son HEAD d’exécution b1f. Les identités et captures de cette exécution ne sont pas retargetées vers le présent commit. Aucune image ni aucun service de chaîne ne sont reconstruits ou redémarrés pour ce lot. Aucune production n’est déclarée prête.
