# InventoryV2 : racine initiale indépendante

Une seule transition **vide** avec Geth officiel `evm 1.16.7`, sous Shanghai, retrouve exactement la racine initiale Native `0x59b1d26c399cf72a530c508fd24c52b6375ce7adfe54fd7d37fbf33431886d7e`. Le postétat contient toujours les trois comptes publics de fixture, chacun avec solde 10²⁴, nonce zéro, code et stockage vides. Le gaz total vaut zéro. Aucun client Native, compilateur, nœud de consensus ou transaction signée n'est exécuté par ce complément.

Le [terminal Root](root-result-public.json) constate Docker exit0, sans échec primaire ou secondaire, en 1,915 seconde. Le [pilote](controller-public.json) observe une commande Geth exit0/close0, avec groupe joint. Il ferme 21 FD explicitement suivis au terminal, dont son dernier fichier de publication ; le contrôleur Root ferme ses 31 FD séparés. Le rapport du pilote conserve `passed:false` avec `terminalEvidenceReady:true` et exige le vrai terminal externe. Ces compteurs ne prétendent pas recenser tous les descripteurs du système.

Le [contrôle](control-public.json) épingle les entrées externes. L'allocation est celle du premier passage Geth conservé, SHA `abb3a67d69f1a197c4279aa271df5e7c65b32f07bf8d1bad50d0faac9a0fc236`, 459 octets. Le contexte reprend les bytes d'environnement déterministes du producteur original : timestamp 1700000012, coinbase 0x9999, gasLimit 60M, baseFee zéro, Random zéro et retraits vides ; chainId 31337 est passé séparément à t8n. Aucune continuité physique historique de ce fichier n'est revendiquée. La liste de transactions est la chaîne JSON RLP vide `0xc0`, récompenses désactivées par `--state.reward=-1`.

Le [résultat Geth](result.json), le [postétat](post.json), la [commande](command.json) et tous les fichiers publiés sont épinglés dans le [manifeste](manifest-public.json). Les champs zéro omis par Geth sont admis uniquement pour vérifier sémantiquement le postétat ; les bytes de l'allocation ne sont jamais normalisés ou réinjectés. Le binaire `7bad7839…` est celui dont la provenance signée et la version étaient déjà retenues dans la [qualification Geth des 65 transactions](../inventory-v2-geth-t8n-20261025/README.md).

Ce complément traite la racine initiale non comparée par le précédent pilote. Il ne rejoue pas ses 65 transactions et ne modifie aucun de leurs verdicts. Les [engagements de reçus](../inventory-v2-receipts-20261025/README.md) restent un lot distinct. Aucun fork supplémentaire, bloc miné, RPC/P2P, consensus, bridge ou lancement n'est qualifié ici. Les échecs historiques, la revue de sécurité indépendante et tous les critères non démontrés restent ouverts ; la production n'est pas déclarée prête.
