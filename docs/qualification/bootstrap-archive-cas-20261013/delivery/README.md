# Archive signée du bootstrap Capella — livraison publique ciblée

Ce paquet lie les six sources à la base Git `4228fcdaec166b32f6ad87bf8dd08c1459384bb0`. Le cœur V3 et le test V4 ajoutent une preuve possédée de la transition Genesis 0 → slot 1, puis un supplément atomique explicite d’une archive déjà signée, avec pins PRIMARY et WITNESS distincts. La publication ordinaire et son raccourci de déduplication restent protégés. `delivery.patch` et `source/` sont les octets finaux proposés, sans édition du dépôt par le préparateur.

Les constructions cohérentes produisent chacune 141 membres. Les trois CTests ciblés passent sur Docker Linux ARM64 et AMD64 : le nouveau test archive CAS, la frontière d’annulation de publication et la reprise cold-memo par SIGKILL. Chaque architecture a dix scénarios nouveaux puis un résumé ; ces lignes ne constituent pas onze tests séparés. Le test neuf mesure 637 ms / 25 236 KiB sur ARM et 2 237 ms / 26 520 KiB sur AMD. Il crée zéro signature, utilise uniquement des bases synthétiques possédées et vérifie deux interruptions SIGKILL, dont un modèle explicite de perte de suffixe WAL.

`history.json` conserve les deux findings, l’ancienne revue V2 corrigée, les trois refus réels et les réparations ciblées. Les manifests propriétaires gardent leur ancien statut de proposition : les résultats réels sont dans `arm64/` et `amd64/`. `source-closure.json` relie les contrôles publics de sources, SDK, objets et lecture après tests ; les gros plans et inventaires ne sont pas recopiés. Le SHA du manifeste final doit être conservé extérieurement.

La campagne privée n’a pas été modifiée ou restaurée. Les duties et l’avancement d’une finalité commune restent ouverts, ainsi que les cas à files durables non vides, les interruptions des formats cold/fragment et la panne physique. Les quatre preuves privées VPS, la qualification de l’horloge actuelle et l’allowance administrative finie restent dans leur périmètre d’autorisation et de validation antérieur. Aucun état EIP, fork, bridge, lancement ou production n’est promu. Aucun binaire, objet, archive compilée, DB, clé, capsule, fichier d’environnement ou inventaire privé n’entre dans ce paquet.
