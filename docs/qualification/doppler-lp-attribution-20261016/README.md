# Attribution des liquidités lors de la migration Doppler V2

Le vérificateur exige désormais un crédit LP attribuable à cette migration. Un ancien solde positif ne suffit plus. Pour le migrateur Base V2 historique `0x5F3bA43D44375286296Cb85F1EA2EBfa25dde731` (`asset[3]`), le reçu lié doit montrer un mint unique au migrateur, puis un transfert au bénéficiaire (`asset[1]`) sur la paire (`asset[6]`). Tous les débits du bénéficiaire dans le reçu sont soustraits du crédit attribuable ; une donation étrangère ne masque pas son annulation. Self-transferts, logs malformés et attribution ambiguë sont refusés. Les six lectures EIP-1898 et les barrières de header sont conservées. Aucun pourcentage de répartition économique n'est ajouté.

Le candidat passe 29/29, zéro skip, avec les nouvelles copies Linux inchangées et les anciennes sources/Node contrôlées inchangées. Une seule image existante, réseau désactivé, aucun Anvil, transaction, compilation C++ ou build d'image.
