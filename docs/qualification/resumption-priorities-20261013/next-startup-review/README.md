## Erreurs bloquantes à conserver

`Capella startup catch-up requires unused healthy clock and explicit bounds` ; `local clock discontinuity` (recul, saut local entre deux observations >pas) ; `downtime budget exceeded` ; `step budget exceeded` ; replay capacity dépassée ; token primaire/témoin ou domaine faux ; source/copies non authentifiées ; binaires/headers/archives mélangés ; diff non revu ou assets obsolètes ; worker/stop ambigu ; aucun nouvel avancement commun avantdeadline.

Un refus step/cancel/jump peut laisser un **préfixe durable déjà publié**. Conserver l’intent témoin et ce token primaire, arrêter, capturer et faire une reprise nouvelle conforme : jamais réinjecter le token antérieur ni supprimer la base. Une absence économique pure de comité ne devient pas une faute fatale du scheduler avec le candidat, mais aucune liveness n’est garantie si aucun parent valable/validateur futur ne reste. Le chemin plat refusé à137524 Kio, le V37 de cinq jours et les autres gates de production restent ouverts.
