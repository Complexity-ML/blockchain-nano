## Défaut réel trouvé, pas seulement des mocks

L’essai Docker01 a passé le premier scénario stdin, puis échoué sur les groupes
réels et expiré à150s. Son conteneur exact a été supprimé et son absence vérifiée.
Le lanceur utilisait execFile avec detached ; [le code Node18.19.1](https://raw.githubusercontent.com/nodejs/node/v18.19.1/lib/child_process.js)
ne transmet pas cette option à spawn. Le correctif utilise directement spawn,
collecte les deux flux avec bornes, conserve la première erreur et attend close
ET l’absence du groupe. Les annulations falsy et l’admission vieillie avant spawn
ont aussi reçu des cas causaux. Les propositions source refusées restent locales.
