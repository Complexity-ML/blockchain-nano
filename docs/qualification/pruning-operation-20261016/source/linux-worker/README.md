## Résultat et limites

`result-public.json` et stdout sont le même objet public ; Root compare leurs bytes et conserve les anciennes fences hôte, sortie/cleanup compris. Le résultat engage SHA+octets de `software-admission.private.json` produit par cette invocation. Celui-ci conserve les lignes guest, résolutions, produits, Core ancien/nouveau, oracle et première admission ; ses bytes privés ne sont pas livrés par l’auteur. Une erreur après admission du nouveau namespace conserve seulement le refus, l’étape, les compteurs et l’état de fence/cleanup, sans publier de message ou chemin d’exception.

Le succès futur resterait borné aux sources/propositions et à ces fixtures synthétiques dans un conteneur. `sourceRevisionDeclared` n’est pas une vérification Git par le worker, ni la preuve d’un configure CMake complet. `storageSourceModified:false` vient du test SST et signifie storage.cpp inchangé ; l’archive composée remplace bien un objet runtime. Aucun nouveau runtime, HTTP, chargement exhaustif/lazy, ancien SDK réadmis, DAG complet, 24 admissions, campagne, finalité ou production n’est qualifié. Les signatures nouvelles éventuelles sont64 signatures ECDSA de fixture, jamais zéro signature universellement.
