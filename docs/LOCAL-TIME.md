# Local time for Capella

The strict existing clock rejects any backward sample. The optional `clock.maximumWallClockDriftMs` selects one local monotonic source shared by clock polling, validator duties, admission callbacks and Beacon runtime observations. It is an explicit positive canonical hex quantity, smaller than both the profile attestation deadline and `maximumForwardStepMs`. No default tolerance or peer time is introduced.

At startup, this source anchors wall time to steady time. It returns anchor plus elapsed steady milliseconds; bounded wall corrections never alter that timeline. It compares wall time against that projection on every read. Divergence beyond the configured budget, a backward steady sample, source exception or integer overflow latches failure until restart. The existing clock still enforces forward recovery bounds and rejects startup behind persisted consensus time. The budget applies to cumulative divergence from the startup anchor, not a per-poll allowance that could accumulate unlimited skew.

Choose the budget from measured clock synchronization and your profile deadline, not transaction throughput. The qualification selection `NANO_TEST_WALL_CLOCK_DRIFT_MS` accepts positive decimal milliseconds and writes the equivalent quantity into fresh private configurations. A250ms example would use `maximumWallClockDriftMs: "0xfa"`; that is a test parameter, not a production recommendation or default. Large system adjustments or suspension can still stop the node. Diagnose and resynchronize the host clock before restarting from intact independently pinned witnesses/journals; never reset journals to bypass a fault.

Unit injected-time checks cover bounded forward/backward adjustments, exact boundaries, latched large drift, steady regression, source exceptions, overflow and concurrent observations. Runtime integration checks cover configuration rejection before checkpoint publication and selected-source startup. These do not establish network finality, all failure recovery or production readiness; the real pruned restore/load campaign remains a separate gate.
