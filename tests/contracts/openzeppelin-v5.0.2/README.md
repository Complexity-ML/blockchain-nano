# OpenZeppelin Contracts v5.0.2 test dependency

Unmodified production Solidity sources from
https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.0.2
under the included MIT LICENSE. All 143 production Solidity files are included;
upstream mocks, JavaScript tests and build scripts are not bundled.

These are test inputs, not deployed production contracts. See
`docs/OPENZEPPELIN-QUALIFICATION.md` for coverage, gaps and reproduction commands.
`tests/fixtures/openzeppelin-catalog.json` inventories every source and component.
Ordinary CMake/CTest execution uses frozen bytecode and requires no Node.js,
Solidity compiler or Python runtime. Compilation of the catalogue is not proof
of runtime compatibility or production readiness.
